**Conclusion for Level 1:** SDXL, SSD-1B and Vega share one latent space (SDXL's VAE; SSD-1B's
copy is the fp16-fix variant, which the bench uses for everyone anyway) and the same Euler
schedule, so a mid-generation latent handoff between any two of them is well defined. Sharing
SDXL's text encoders across all three UNets is safe. The notebook still confirms this with a
real handoff image, which remains the gate.
